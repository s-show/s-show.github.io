## 前置き

仕事で登記簿の面積の坪から平方メートルへの換算について調べる必要に迫られましたので、調べたことを備忘録としてメモします。

## 度量衡法を元にした換算

### 坪の定義

明治24年3月24日法律第3号「度量衡法」第3条で「1坪: 6尺平方」と定められていましたので、縦横の長さが6尺の正方形の面積が1坪になります。

### 尺・間の定義

度量衡法第1条は

> 度量ハ尺、衡ハ貫ヲ以テ基本トス

と定め、「尺」を尺以外の単位の基準としています。

具体的には、「寸」は尺の10分の1、「間」は6尺という形で尺を使って他の単位が定義されています。そして、尺自体の長さは、度量衡法第2条で次のとおり定義されています。

> 度量衡ノ原器ハ白金「イリヂウム」合金製ノ棒及分銅トス
> 其ノ棒ノ面ニ記シタル標線間ノ摂氏0.15度ニ於ケル長サ三十三ノ十ヲ尺トシ分銅ノ質量四分ノ十五ヲ貫トス
> （改行を追加し、旧字の「攝」を「摂」に変えている）

この条文だけでは原器の大きさが不明ですが、ここでいう原器は国際メートル原器のNo.22を指しているようです（[メートル条約締結と原器の来日：国立研究開発法人産業技術総合研究所 計量標準総合センター](https://unit.aist.go.jp/nmij/library/nmij_icp/introduction.html) 参照）

そして、尺とメートルの関係については、第5条で「1尺 = 33000分の10000メートル（注：約分すると33分の10）」、「1尺 = 0.30303メートル」と定義されています。なお、間については、「1間 = 11分の20メートル」、「1間 = 1.81818メートル」と定義されています。

### 坪から平方メートルへの換算

これらを合わせると、以下の数式で坪から平方メートルに換算できます。

1坪 = 1間 * 1間 = (11/20)^2 = 121/400 平方メートル = 3.3057785124...平方メートル

## 登記簿の面積の換算

登記簿の面積を坪から平方メートルに書き換える際の計算については、昭和41年3月1日民事甲第279号民事局長通達で示されています。

同通達では、面積が1万坪以上なら「1坪 = 121/400 平方メートル」で計算するよう定め、1万坪未満なら「1坪 = 3.30578512 平方メートル」とした換算表をベースに書換えるよう定めていました。

その上で、面積に応じて以下の計算によって求めた面積を用いても差支えないものとしていました。

1坪未満
: 1坪 = 3.3057 平方メートル として計算

1坪以上10坪未満
: 1坪 = 3.30578 平方メートル として計算

10坪以上100坪未満
: 1坪 = 3.305785 平方メートル として計算

100坪以上1,000坪未満
: 1坪 = 3.3057851 平方メートル として計算

1,000坪以上10,000坪未満
: 1坪 = 3.30578512 平方メートル として計算
